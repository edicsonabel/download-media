# download-media 0.2.0

This release makes browser cookies and Instagram carousels work reliably, and makes the tool tell the truth about what it saved.

## What you need to do

- **AUR users:** update as usual. The package now depends on `python-curl_cffi`, which comes from the official `extra` repository, so `yay`, `paru` or `makepkg -si` install it for you.
- **Installed from source:** run the install again to pick up `curl_cffi`. Without it, public Instagram posts fail.
- **Scripts using `-p`:** a playlist or carousel where nothing could be saved now exits with an error. It used to exit 0.

No flags were renamed, no defaults changed, and your history file stays where it is.

## New

- **Choose the keyring for browser cookies.** `--cookies` now accepts `BROWSER[+KEYRING]`, for example `--cookies brave+gnomekeyring`. The keyrings are `basictext`, `gnomekeyring`, `kwallet`, `kwallet5` and `kwallet6`. Plain `--cookies brave` works as before.
- **Clearer results for carousels.** When only part of a carousel is saved, the run says how many items were saved, how many had nothing to download, and how many failed.

## Fixed

- **Cookies from Chromium browsers.** Brave, Chrome, Chromium, Edge, Opera and Vivaldi can store their keys in a different keyring from the one your desktop uses. That made cookies fail to decrypt, and sites answered with errors that looked unrelated. The tool now reads `--password-store` from the browser's flags file, such as `~/.config/brave-flags.conf`. If you set it somewhere else, a failed run tells you how to name the keyring by hand.
- **Public Instagram posts without cookies.** These work now, thanks to `curl_cffi`.
- **Carousels stopping at the first image.** With `-y`, a carousel used to abort at its first image. Images are now skipped and the videos are downloaded.
- **Carousel videos being lost.** Items in a carousel share the same title, so all but the first could be skipped as duplicates. Without `-p`, each one now gets its id in the file name, like `Title [id].mp4`.
- **False success with `-p`.** A total failure used to print "Done" and never retried without cookies. It now reports the failure, and does retry.
- **A carousel with nothing to download** now counts as a failure.
- **`-l` crashing.** Listing formats no longer ends in a traceback on carousels or when the site returns an error.

## Known limitation

Carousel images are still not saved: they are skipped, and the run reports them.
